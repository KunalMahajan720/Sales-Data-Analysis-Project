## Power BI Dashboard Project:** **Swastik Roadlines Sales Data Analysis**

This project involves creating an interactive Power BI dashboard to analyze Swastik Roadlines' sales data. The dashboard provides key insights into sales performance, revenue trends, and customer demographics. It includes visualizations such as bar charts, pie charts, and line graphs to track sales across different time periods, regions, and product categories. The dashboard also enables users to filter and drill down into specific data points, providing deeper analysis of the sales pipeline and supporting decision-making.
